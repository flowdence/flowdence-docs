Build A Supabase Runbook Page

This tutorial uses a Supabase dashboard as the example source. The same pattern works for any service dashboard your Grafana service account can read.

1. Start In Grafana

Section titled “1. Start In Grafana”

Open the source dashboard and choose the time range that matches your runbook. The verified example used a Supabase project dashboard with CPU, load, memory, swap, disk, core count, and uptime panels.

2. Find The Dashboard In GrafanaSight

Section titled “2. Find The Dashboard In GrafanaSight”

Open GrafanaSight in Confluence and search for the service name. Open the dashboard detail view to inspect panels and copy macro links.

3. Preview A Panel

Section titled “3. Preview A Panel”

Use the snapshot preview before inserting the panel into a runbook. This confirms that the panel renders and that the selected time range is useful.

4. Build The Runbook Page

Section titled “4. Build The Runbook Page”

Add:

  • A short service summary.
  • One dashboard macro for orientation.
  • Two or three high-signal detailed panel macros.
  • Compact panel macros for supporting metrics.
  • Alert summary or status badge macros near response steps.
  • Annotation context near any panels that need change history.

5. Refresh The Page

Section titled “5. Refresh The Page”

After inserting macros, publish the page and use the GrafanaSight refresh byline to refresh the page’s GrafanaSight macros.
